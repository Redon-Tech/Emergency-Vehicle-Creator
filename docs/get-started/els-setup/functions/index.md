# Function Setup

Functions control groups of lighting patterns. For example, a **Stages** function can contain several patterns that you switch between while playing.

## Create a function

EVC starts with two functions:

- **Stages**
- **Traffic Advisor**

You can add more if you need them.

To add one:

1. Enter a name in **New Function Name**.
2. Click **Add**.

The new function starts with one empty pattern and a default activation.

## Change a function

Open a function to change its settings.

You can:

- change its name
- change its **weight**
- add, edit, or delete patterns
- change its activations

### Weight

Weight decides which function gets priority when two functions use the same light.

A higher weight has priority over a lower weight.

## Patterns

Open a function and choose **Patterns** to see its patterns.

Click **Add Pattern** to create another pattern.

Patterns do not have names. They are identified by their number.

Click **Edit** on a pattern to open the pattern editor.

## Activations

Switch to the **Activation** tab to decide how the function changes patterns.

For example, a function can use a keybind to cycle through its patterns.

See **[Activations](activations.md)** for the available options.

## Default controls

The default vehicle setup includes:

- **Stages:** J / DPadLeft
- **Traffic Advisor:** K / DPadRight

You can change these in the activation settings.
