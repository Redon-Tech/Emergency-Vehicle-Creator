Light Settings controls how EVH changes the lights on the vehicle.

The page has three sections:
- **Settings**
- **Colors**
- **Light Groups**

## Settings

### Enabled Effects

These options control which types of Roblox light objects EVH changes:
- **Enable Neon Lights**
- **Enable Light Emitters**
- **Enable Lightos**
- **Enable Particle Emitters**

Particle emitters are disabled by default.

### Light Configuration

**Part Transparency** controls the transparency used for light parts.

Enter a number and leave the field to save the value.

## Colors

Each color has four values:
- **Name**
- **Part Color**
- **Light Color**
- **Lighto Color**

The first six colors are built in:
- Blue
- Red
- Yellow
- White
- Green
- Purple

The built-in color names cannot be changed or deleted.

Click **Add Color** to create another color. User-created colors can be renamed, edited, and deleted.

When a color is deleted, EVC removes references to that color from flashers, faders, and rotators.

## Light Groups

Light groups let several light names be treated as one group.

Click **Add Light Group** to create one.

You can:
- rename a group
- expand or collapse a group
- select lights for the group
- remove lights from the group
- delete the group

Hold **Left Shift** while selecting lights to select a range.

A light can only be added once to the same group.

Group names are made unique by EVC.

!!! note
    The light names shown here come from the equipment on the vehicle. If a light does not appear, check the equipment setup and its Light Prefix.
