# V2 to V3 Conversion

If you have a vehicle made with an older version of EVC, EVC can convert its existing setup to the current version when the old setup is found.

## What gets converted?

EVC can convert the old settings for:

- functions
- patterns
- keybinds
- flashers
- faders
- rotators
- sirens
- siren modifiers
- light settings

## Convert your vehicle

1. Select your older EVC vehicle in Roblox Studio.
2. Open EVC.
3. Start the normal vehicle setup/install process.
4. If EVC finds the old setup, follow the prompt to install the current system.
5. Check your functions, sirens, and light settings after the conversion.
6. Use **Export** when you are happy with the result.

The old module is kept as a backup after the conversion.

!!! note
    Conversion uses the settings that are present in the old vehicle. If required data is missing, some settings may not be converted.
