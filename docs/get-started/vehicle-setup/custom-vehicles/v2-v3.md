EVC V3 can convert older EVC Chassis Plugin data when the old setup is found on a vehicle.

When EVC installs the current Emergency Vehicle Handler, it checks for the old EVC Chassis Plugin and converts its configuration to the V3 format.

## What is converted

The conversion code reads the old configuration and rebuilds the parts used by V3, including:
- functions
- patterns
- keybinds
- flashers
- faders
- rotators
- sirens
- siren modifiers
- light settings

Old function and pattern data is converted into the current EVH configuration modules.

## What to do

1. Select the old EVC vehicle in Roblox Studio.
2. Open EVC.
3. Start the normal vehicle setup/install process.
4. If the old EVC Chassis Plugin is detected, EVC offers to install the Emergency Vehicle Handler.
5. Confirm the install.
6. Check the converted functions, sirens, and light settings.
7. Export the vehicle after checking the result.

The old module is kept as a backup after conversion.

!!! note
    Conversion is based on the old configuration data that EVC can read. If the old vehicle is missing required data, some settings may not be converted.
